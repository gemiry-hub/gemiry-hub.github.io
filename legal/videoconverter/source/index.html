LGPL Source Code for Video Converter

Last updated: November 3, 2026

Video Converter on Android, made by Gemiry Company Limited ("Gemiry," "we," "us," or "our"), ships two libraries licensed under the GNU Lesser General Public License (LGPL):

  • FFmpeg 7.1 — libavformat, libavcodec, libavutil, and libswscale;
  • LAME 3.100 — the libmp3lame MP3 encoder.

This page offers their source code, and the scripts used to build them for the App, as the App's third-party notices promise. There is one archive per released version of the App.

2. What each archive holds

Each archive unpacks to one folder, video-converter-<version>-lgpl-sources/, containing:

Path Content
ffmpeg/ The complete FFmpeg source at commit b08d7969c550a804a59511c7b83f2dd8cc0499b8 (tag n7.1), with its licence COPYING.LGPLv2.1
lame-3.100/ The LAME 3.100 source, unmodified, with its licence COPYING
build/native/ffmpeg/ build-ffmpeg.sh (the exact FFmpeg configure line), PINNED_COMMIT, and a README
build/core/engine/src/main/cpp/ CMakeLists.txt, the LAME config.h, and the JNI bridge sources that link to the libraries
build/shipped.sha256 The SHA-256 of each FFmpeg library file that shipped in the App
README.md What each part is, the versions, the toolchain, and the rebuild steps
MANIFEST.sha256 The SHA-256 of every file in the archive except itself and the README

3. Checking the download

  • The archive: compare its SHA-256 with the value above, for example with sha256sum -c video-converter-1.0.0-lgpl-sources.tar.gz.sha256, or on Windows Get-FileHash -Algorithm SHA256.
  • Its contents: extract it, change into video-converter-1.0.0-lgpl-sources/, and run sha256sum -c MANIFEST.sha256.

4. Rebuilding the libraries

The App links these libraries dynamically (libmp3lame.so, libavformat.so, libavcodec.so, libavutil.so, libswscale.so), so you can replace any of them with your own build of the same source. The archive's README.md has the full steps. In short:

  • Toolchain used: Android NDK 30.0.15729638, CMake 4.1.2, Android API 26, ABIs arm64-v8a, armeabi-v7a, and x86_64. FFmpeg is built with MSYS2.
  • Copy ffmpeg/ to build/native/ffmpeg/ffmpeg/ and lame-3.100/ to build/native/lame/.
  • Build FFmpeg one ABI at a time with build-ffmpeg.sh <abi> --prebuilt in build/native/ffmpeg/, and compare the results with build/shipped.sha256.
  • Build libmp3lame.so and the bridge library with build/core/engine/src/main/cpp/CMakeLists.txt, once per ABI.
